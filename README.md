## Назначение

Приложение предназначено для изучения и демонстрации сортировок:

1. **Внутренняя сортировка** — Odd-Even Sort, Tournament Sort и Gnome Sort с пошаговой визуализацией, турнирным деревом, таблицей и журналом.
2. **Внешняя сортировка** — Natural Merge Sort и External Merge Sort с реальными временными файлами, сериями и сохранением результата.
3. **Сортировка текста** — QuickSort и Unicode Radix Sort, подсчёт частот слов и сравнение производительности.

Пользователь может управлять скоростью, ставить демонстрацию на паузу, выполнять операции по одной, останавливать и сбрасывать процесс. Все длительные операции выполняются в фоне и поддерживают отмену.

## Реализованные алгоритмы

| Алгоритм | Раздел | Сложность | Память | Особенности |
|---|---|---|---|---|
| **Odd-Even Sort** | Внутренняя | O(n²) | O(1) | Устойчив, чётная/нечётная фазы |
| **Tournament Sort** | Внутренняя | O(n log n) | O(n) | Турнирное дерево, отдельный результат |
| **Gnome Sort** | Внутренняя | O(n²), лучшее O(n) | O(1) | Устойчив, возврат назад при нарушении порядка |
| **Natural Merge Sort** | Внешняя | O(n log R) | O(1) записей в буферах | Находит готовые серии, реальные файлы, устойчивость |
| **External Merge Sort** | Внешняя | O(n log n) | O(1) записей в буферах | Прямое слияние, начальные серии по одному элементу |
| **QuickSort** | Текст | O(n log n) с introsort | O(log n) | Median-of-three, 3-way partition |
| **Radix Sort** | Текст | O(d·(n + 65536)) | O(n + 65536) | LSD по UTF-16, Unicode |

Встроенные `Array.Sort`, `List.Sort` и `OrderBy` **не используются** для получения результата сортировки.

### Правило сравнения текста

Оба текстовых алгоритма получают одинаковые нормализованные слова:

- Unicode Normalization Form C;
- `ToLowerInvariant`;
- только буквы и цифры, пунктуация удаляется;
- лексикографический порядок по кодовым единицам UTF-16;
- если строка является префиксом другой, короткая идёт раньше.

Правило одинаково для QuickSort и Radix Sort, не зависит от локали и документировано в `docs/algorithm-design.md`.

## Разделы приложения

### 1. Внутренняя сортировка

- Выбор Odd-Even Sort / Tournament Sort / Gnome Sort.
- Генерация массива: размер 0–200, минимум, максимум.
- Ручной ввод целых чисел через пробел, запятую или точку с запятой.
- Столбчатая диаграмма с цветами операций.
- Таблица: индекс, значение, состояние.
- Журнал: номер шага, тип, индексы/значения, пояснение.
- Отдельная вкладка турнирного дерева для Tournament Sort.
- Отображение текущей позиции для Gnome Sort.
- Пояснение текущей операции простым языком.
- Карточка алгоритма: идея, принцип, сложность, память, особенности.
- Итоговая статистика и исходный/отсортированный массивы.
- Управление: запуск, пауза, продолжение, шаг, остановка, сброс, скорость.

### 2. Внешняя сортировка

- Выбор алгоритма: Natural Merge Sort или External Merge Sort.
- Встроенная таблица 195 стран или собственный CSV.
- Фильтр по континенту (для таблицы стран).
- Выбор ключевого столбца, типа (строка/целое/вещественное) и направления.
- Отображение исходной таблицы и результата слияния.
- Полоса естественных серий с номерами и количеством записей.
- Панель сравниваемых записей.
- Журнал чтения, сравнений, выбора и записи.
- Сохранение всех исходных столбцов в CSV.
- Путь к результату и кнопка открытия папки.
- Временные файлы удаляются после завершения или отмены.
- Сортировка устойчива: равные ключи сохраняют исходный порядок.

### 3. Текст и эксперименты

- Загрузка TXT-файла или генерация текста из словаря.
- Воспроизводимая генерация: одинаковый seed и размер дают одинаковый текст.
- Английский, русский или смешанный словарь.
- Выбор QuickSort / Radix Sort.
- Таблица частот слов с поиском, общим числом слов, числом уникальных и топ-5.
- Эксперименты на 100, 500, 1000, 2000, 5000+ словах.
- Настройка повторений и seed, прогресс и отмена.
- Таблица результатов (медиана) и график с двумя сериями, подписями, легендой и логарифмической шкалой при большой разнице.

## Форматы файлов

### CSV для внешней сортировки

- Первая строка — заголовки.
- Поддерживаются разделители `,`, `;`, табуляция, `|` (определяется автоматически).
- Кавычки и экранированные кавычки (`""`) поддерживаются.
- Допускаются переносы строк внутри кавычек.
- Пустые значения разрешены; для числового ключа пустое значение считается меньшим.
- Количество столбцов не ограничивается пятью.
- Некорректное число в числовом ключе приводит к понятному сообщению; сортировка не начинается.
- Максимальный размер загружаемого CSV — 64 МБ (защита от случайной загрузки гигантского файла).
- Результат сохраняется в UTF-8 с BOM, разделитель — запятая, все поля экранируются по RFC 4180.

### TXT для текстового раздела

- Кодировка UTF-8 (BOM допускается).
- Максимальный размер — 16 МБ.
- Слова выделяются как последовательности букв и цифр; пунктуация и лишние пробелы игнорируются.

## Эксперименты

- Размеры по умолчанию: 100, 500, 1000, 2000, 5000; можно ввести свои.
- Для каждого размера генерируется один массив слов; оба алгоритма получают одинаковые данные.
- Выполняется прогрев и несколько повторов (по умолчанию 5).
- В таблицу попадает медиана.
- Время генерации текста, копирования массива, построения таблицы и отрисовки не входит в замер.
- QuickSort и Radix Sort получают одинаковые нормализованные слова и одно правило сравнения.
- Результаты проверяются на совпадение и упорядоченность.

## Тестирование

```powershell
dotnet test -c Release
```

Покрытие тестами:

- Odd-Even Sort и Tournament Sort: пустой массив, один элемент, сортированный, обратный, дубликаты, отрицательные значения, большие массивы, отмена, статистика, снимки шагов.
- Gnome Sort: граничные случаи, сортированный и обратный массивы, дубликаты, отрицательные значения, отсутствие перестановок на равных элементах, статистика и события позиции.
- External Merge Sort: начальные серии по одному элементу, несколько проходов, устойчивость, сохранение полей, удаление временного каталога.
- CSV: разделители, кавычки, переносы, пустые значения, неровные строки, дубликаты заголовков.
- Внешняя сортировка: пустая таблица, одна запись, сортированный/обратный порядок, устойчивость, строковый/целый/вещественный ключ, произвольные столбцы, сохранение всех полей, файловые события, удаление временного каталога.
- Текст: пустой текст, одно слово, регистр, пунктуация, кириллица/латиница, префиксы, разные длины, совпадение QuickSort и Radix Sort, частоты, воспроизводимость генератора, бенчмарки.
- Проигрыватель: запуск до завершения, ручной шаг, пауза/продолжение, ошибка, сброс, журнал.

Актуальный результат: **97 тестов, все проходят**.

## Ограничения демонстрации

- В визуализации внутренней сортировки — до 200 элементов (алгоритмы тестируются и на больших массивах).
- Внешняя сортировка демонстрируется на 195 странах или пользовательском CSV; промежуточные данные действительно хранятся в файлах.
- Турнирное дерево читаемо для типичных демонстрационных размеров; для больших массивов оно масштабируется.
- Загружаемый CSV ограничен 64 МБ, TXT — 16 МБ; это защита UI, а не ограничение самих алгоритмов.
- Текстовые эксперименты по умолчанию используют английский словарь (рекомендация из задания — меньше словоформ).
